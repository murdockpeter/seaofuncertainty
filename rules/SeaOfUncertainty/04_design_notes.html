Design Notes • v0.5

What Are We Testing Now?

v0.5 is detailed enough to expose where the game works and where more realism may actually be useful.

Current Thesis

One loop: Ready → Choose → Posture → React → Resolve → Entropy → Schedule.

Must Prove

  1. Ready Time creates tempo without bookkeeping.
  2. Missions reduce chores without reducing agency.
  3. Search and Contact Age matter repeatedly.
  4. Combat stays tactile.
  5. Bounded luck feels fair.
  6. Entropy explains degradation.
  7. Command Slots create prioritization.
  8. Synchronization is strong but not automatic.

Known Abstractions

Air, submarine warfare, missile defense, weapon inventories, logistics, and EW are still intentionally coarse. Add detail only after the chassis proves fun.

Recommended Test

  • 8 total Formations.
  • 12×10 map.
  • 12–16 Time spaces.
  • One central objective.
  • One/two chokepoints.
  • One ambiguous or false Contact.

Record

  • Every obvious choice.
  • Repeated lookup.
  • Inactive-player lull.
  • Unfair-feeling die result.
  • Unused action.
  • Dominant action.
  • Contact Age changing a decision.
  • Command Slot scarcity.

Next Detail Layers — Only If Earned

  1. Distinct surface/sub/air behavior.
  2. Nuanced Search/Signature.
  3. Layered missile defense.
  4. Weapon expenditure.
  5. Scenario logistics.
  6. EW/deception.
  7. Different command architectures.
